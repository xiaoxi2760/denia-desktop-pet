娅娅 · 独立 AI 设置

没有「大脑」（bot）也能对话和语音：直接连一个兼容 OpenAI 的模型接口，鸣潮官方·达妮娅的人设卡会自动注入（不需要任何 QQ / 主机）。

填法示例 —— DeepSeek：地址 https://api.deepseek.com/v1 ＋ 模型 deepseek-chat；MiniMax：地址 https://api.minimax.cn/v1 ＋ 模型 MiniMax-M3。地址只填到 /v1 结尾即可（后面的 /chat/completions 会自动接上，不要再带别的路径）。「看看屏幕 / 陪看」需要模型支持看图（视觉模型），每看一眼会消耗一点你 Key 的额度。

没有装过 GPT-SoVITS 就用上面第三种（Fish Audio），不用在自己电脑装任何东西。

平台支持"上传音频克隆音色"的话，音色名就填克隆出来那个。

复制粘贴别手打：AppID/Token 在"语音技术 → 应用管理"；声音 ID 在"声音复刻 → 我的音色"。集群栏默认 volcano_icl 就是复刻音色用的。

音色快速复刻在 MiniMax 开放平台（需先完成个人认证）；复刻出的音色 7 天内要正式用一次，否则平台会回收。

新版控制台在 console.volcengine.com/speech/new：「API Key」页创建密钥；克隆的音色在「声音复刻 → 我的音色」。AppID 是旧版接口才要的（它藏在新版 API Key 页右上角的小链接「APP ID ›」里）。
