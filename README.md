# 娅娅 · 桌面宠物

一个住在桌面上的 MMD 角色（three.js 渲染 + 物理 + 语音），通过一个简单的 HTTP 接口和"大脑"对话。

- **她会自己困**：你没动鼠标键盘超过 60 秒，她就打瞌睡；你一回来她一激灵
- **她会走位**：跟你的鼠标、时不时溜到角落坐着
- **她能说话**：打字、语音输入（按住 🎤 或免提）、语音输出
- **她会主动冒泡**：轮询后端，她想说话的时候自己冒出来

---

## 一、安装

前置：**Node.js 18 或更高**（[nodejs.org](https://nodejs.org) 下载 LTS 版）。

```bash
# 在这个目录里
npm install
```

第一次会下载 Electron（约 150 MB），耐心等一会儿。

然后双击 **`启动娅娅.cmd`**，或者：

```bash
npm start
```

> 首次启动会先弹出**启动器**：选模型（红/蓝/Solar5 打歌服/白裙绷带）、窗口大小、
> 画质和物理开关再叫她出来；勾选「下次不再显示」可跳过。之后随时从托盘
> 「🚀 启动选项…」改回来。
>
> **想要双击即用的 exe**：双击项目里的 `打包成exe.cmd`，生成
> `发布\娅娅桌宠\娅娅.exe`（免安装，整个文件夹可搬走）。
>
> 她是透明置顶窗口，会出现在屏幕右下角。
> **藏起来 / 叫出来：Ctrl+Alt+Y**（或再双击一次启动程序、或点托盘——Win11 可能
> 把托盘图标收在任务栏右下角的 ^ 溢出区）。

> ### ⚠️ 如果双击之后什么都没发生
>
> 几乎可以肯定是 **DSH（DeepSeek Harness）的工作区沙箱**把 Chromium 的进程沙箱
> 初始化搞崩了，进程会以退出码 `-2147483645`（`0x80000003`）在开窗之前就死掉。
>
> **解决办法：把整个项目目录挪到 DSH 工作区之外**，不加任何启动参数即可正常打开。
> 诊断方法和证据链见 **[`docs/启动故障排查.md`](docs/启动故障排查.md)**。
>
> 请**不要**用 `--no-sandbox` 绕过去 —— 那是安全降级，而且掩盖真因，详见排查文档第四节。

## 二、让她"活过来"：两种模式

### 模式 A · 独立模式（最快，推荐先试这个）

不需要任何服务器，直接连一个 OpenAI 兼容接口就行。

1. 托盘菜单 → **设置**
2. 「模式」选 **启用**
3. 填三项：**API 地址** / **API Key** / **模型**
4. 人设卡留空就用内置的（鸣潮·达妮娅官方向人设）

保存即可。这个模式下：
- 对话历史存在她本地（最近 40 条）
- 语音输出走 Windows 系统 TTS（也可在设置页换 GPT-SoVITS / Fish Audio / 火山 / MiniMax 等七种引擎）

### 模式 B · 联机模式（接自己的后端）

如果你有后端服务，按 [`docs/桌宠对接接口文档.md`](docs/桌宠对接接口文档.md) 实现那 5 个接口，
然后复制 `config.example.json` 为 `config.local.json` 并填写：

```json
{
  "consoleToken": "你的密钥",
  "bridgePort": 3100,
  "ownerQQ": "你的用户名",
  "sshHost": "远程主机别名（同机直连就留空）"
}
```

联机模式下还能用**语音输入**（需要 whisper.cpp，见下）和**看屏幕**（需后端支持）。

## 三、语音输入（可选）

需要 [whisper.cpp](https://github.com/ggerganov/whisper.cpp)：

1. 编译出 `whisper-cli.exe`，下载一个 ggml 模型（如 `ggml-small.bin`）
2. 在 `config.local.json` 里填 `whisperExe` 和 `whisperModel` 的完整路径

不配也能用打字输入，只是没有语音。

## 四、常见问题

| 现象 | 多半是 |
|---|---|
| **双击 cmd 一闪而过，什么都没发生** | **90% 是 DSH 工作区沙箱**。把项目挪到工作区之外 → [`docs/启动故障排查.md`](docs/启动故障排查.md) |
| 退出码 `-2147483645` / `0x80000003` | 同上，Chromium 沙箱初始化失败 |
| `'xxx' 不是内部或外部命令` | `.cmd` 脚本里混进了非 ASCII 字符（尤其破折号 `—`），cmd 按 GBK 解析被切碎 |
| 模型不显示 / 白屏 | 等几秒加载（MMD 模型 + 物理引擎首次加载慢）；还不行看是否有杀毒软件拦了 `tools/foreground.exe` |
| 进程活着但看不到人 | 托盘图标里可能点了"藏起来"，右键托盘 → 出来吧 |
| 说"连不上她" | 联机模式：确认后端在跑、端口对、`consoleToken` 一致；SSH 主机要能免密登录 |
| 她不说话，只显示气泡 | 后端 `reply` 返回了空串——这是正常的"她选择沉默"，不是故障 |
| 没有声音 | 设置页 → 语音引擎 → 确认有可用音色；系统音量 |

## 五、目录说明

```
app/          渲染层（three.js + MMD），main.js 是主要逻辑
electron/     主进程：窗口、截屏、语音、跟后端通信
model/        MMD 模型（红/蓝双形态）
motions/      VMD 动作
assets/       内置人设卡、托盘图标
tools/        foreground.exe（读当前前台窗口）
voice/        语音输出缓存（运行时自动生成）
docs/         接口文档、启动故障排查
```

## 七、第二轮内存优化（2026-10-22）

在保留现有贴图和表情的前提下，提前跳过未使用的表情缓冲，并采用稀疏表情数据。
本地 Whisper 在转写结束后闲置 5 分钟会退出，下次语音再重新加载；忙碌时不会释放。

配置中可选填 `whisperIdleMs`（毫秒，`0` 为保持常驻），不填使用默认值。
测试、对照方式和回退说明见 [第二轮内存优化](docs/第二轮内存优化.md)。
