# 第二轮内存优化（2026-10-22）

本轮在当前“内存优化版”目录继续优化，原版目录保留。贴图、材质、模型文件、默认物理设置和帧率均不降低。

## 变化

- 在加载器生成几何数据前筛选表情，只创建应用需要的 16 个缓冲，减少启动时的临时分配。
- 将表情改为仅保存实际修改顶点的稀疏数据，保留现有眨眼、视线、口型和表情权重。
- 本地 Whisper 服务默认在最后一次转写完成后闲置 5 分钟退出，下一次语音按需重新加载。忙碌、排队和启动期间不会因闲置计时被关闭。
- 连续录音时，被更新录音替代的排队请求会正常结束；旧语音服务退出和新实例启动按顺序处理，探测也有超时。

Whisper 空闲释放后，下一次语音需要重新加载模型，等待时间取决于模型和机器。仅用打字或未启动本地 Whisper 时，这一项不会产生额外节省。

## 可选设置与回退

在现有配置的顶层可选填 `"whisperIdleMs": 300000`（毫秒）；`0` 表示禁用闲置释放。不填就是 5 分钟，无需修改已有配置。

稀疏表情若需对照，可在开发者工具执行以下代码，以 dense 模式重新加载当前形态：

```js
const url = new URL(location.href);
url.searchParams.set('morph', 'dense');
location.href = url.href;
```

删除该查询参数并重载，即回到默认稀疏模式。dense 模式同样使用加载前白名单，但保留全身表情缓冲。
