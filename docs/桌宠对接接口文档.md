# 娅娅桌宠 · 对接接口文档

给**后端实现者**看的。桌宠（Electron 桌面客户端）通过一个本地 HTTP 端点和你的"大脑"通信。

> **写后端之前先确认客户端能起来**：桌宠项目若放在 DSH 工作区内会因沙箱权限标记而
> `-2147483645` 秒退，详见 [`启动故障排查.md`](启动故障排查.md)。
> 另外注意本文件有 3 处与实现不符，以 [`接口总览.md`](接口总览.md)（逐行核对代码版）为准。

- 协议：HTTP / JSON，UTF-8
- 鉴权：所有请求带请求头 `x-console-token: <你的密钥>`
- 连接：桌宠默认会自己拉一条 SSH 隧道 `ssh -N -L 13100:127.0.0.1:<你的端口> <ssh主机>`，
  然后打 `http://127.0.0.1:13100`。如果后端就在本机或局域网内，也可以改配置走直连。
- 配置在桌宠目录下 `config.local.json`：

```json
{
  "tunnelLocalPort": 13100,
  "bridgePort": 3100,
  "ownerQQ": "你的用户名",
  "sshHost": "远程主机别名（直连时留空）",
  "consoleToken": "你的密钥"
}
```

## 接口总览

| # | 接口 | 必需 | 作用 |
|---|---|:--:|---|
| 1 | `GET /api/status` | 必需 | 探活 / 连通性检查 |
| 2 | `POST /api/socialV2/pet-chat` | **必需** | 核心：跟她说一句，拿回她的话 |
| 3 | `GET /api/socialV2/recent` | 建议 | 她**主动**说的话，桌宠轮询冒泡 |
| 4 | `POST /api/socialV2/screen-permission` | 可选 | 看屏幕的许可开关 |
| 5 | `POST /api/socialV2/voice-preview` | 可选 | 语音合成（否则桌宠只用系统 TTS） |

> 只做**最小可用**的话，实现 1 + 2 就能聊天；3 决定她会不会主动找你。

---

## 1 · 探活

```
GET /api/status
→ 200（任意 JSON / 空 body 都行，桌宠只看状态码）
```

桌宠每 1.2 秒超时探一次；探不通就会尝试拉 SSH 隧道。

## 2 · 说话（核心接口）

```
POST /api/socialV2/pet-chat
Content-Type: application/json
x-console-token: <token>

{
  "key": "private:123456",      // 桌宠传固定值，等于"这是同一个用户的私聊窗口"
  "text": "在干嘛",              // 必填，空字符串请直接 400
  "image": "data:image/png;base64,…",   // 可选：base64 / data URL / http(s) URL
  "timeoutMs": 100000                  // 可选：建议回话超时，默认 100s，上限 180s
}
```

### 响应

```json
{
  "ok": true,
  "key": "private:123456",
  "reply": "……没干嘛。",           // 她这一轮说的话；她选择沉默时是空字符串 ""
  "recent": [],                    // ⚠️ 必须恒为空数组，详见下方警告
  "waitedMs": 3120,
  "impl": "pet-chat/v7-quiet-screen"   // 版本标记，桌宠只透传不解析
}
```

> #### 🔴 `recent` 必须恒返回 `[]`
>
> 桌宠把 `recent` 里最大的 `ts` 直接写进 `lastSeenTs` 这个**高水位**
> （`app/main.js:1308-1309`），而主动冒泡取消息的条件是 `ts > lastSeenTs`。
>
> 只要 `recent` 里出现任何一条 `ts` 较大的条目，**比它早、但还没念出来的主动消息
> 就永远不会被念了，而且不报任何错**。所以：
>
> - `recent` 恒返回 `[]`；
> - **本轮的 `reply` 不要同时写进消息表**（它已经被 `reply` 字段念过一遍了，
>   再写进 `/recent` 会重复）；
> - 只有真正主动产生的消息才留在 `/recent` 里等轮询取走。
>
> 本文档早期版本的示例里带了 `recent` 数组，**照着实现会踩这个坑**，特此更正。

### 行为契约（重要）

- **同步阻塞**。桌宠发完就挂着等，最长约 90 秒（客户端硬超时）。
  **请在后端侧先于 90 秒返回**——哪怕她超时没回话，也返回 `"reply": ""`。
- `"reply"` 是**这一轮她说出口的话**，不是提示词回显。
  如果你的架构里模型输出不直接落地（比如要靠"发送消息"工具发出去），
  参考下方[「主动话术型」实现模式](#附两种实现模式)。
- 不认识 `key` 也要接受：桌宠会传固定的 `private:<ownerQQ>`，
  你可以把它当成"这个桌宠用户的固定会话 id"来用——**用它做上下文记忆的 key**。
- 未知字段一律忽略；缺 `text` 或为空 → `400 {"ok":false,"error":"…"}`。

## 3 · 她主动说话（轮询）

```
GET /api/socialV2/recent?key=private%3A123456&limit=20
```

```json
{ "ok": true, "messages": [ { "ts": 1757800000000, "self": true, "text": "喂" } ] }
```

### 桌宠的行为（照抄这段就不会错）

- 每 **4 秒**轮询一次
- 只显示 `self === true` 的消息（`false` 的是主人说的话，桌宠自己会显示）
- 用 `ts`（**毫秒时间戳**）做水位线：`ts > lastSeenTs && self`
- **第一轮只记水位、不补历史**（不要把旧消息一次性全倒出来）
- 收到多条时**逐条排队**念完再念下一条，不叠在一起

⇒ 所以 `ts` 必须**严格递增且唯一**，用毫秒、不要用秒。

## 4 · 看屏幕许可（可选）

```
POST /api/socialV2/screen-permission
{ "watch": true, "minutes": 30, "mode": "quiet" }   // mode: quiet | chatty
```

桌宠点"陪我看屏幕"时触发。你可以用它当开关：`watch:true` 开始、`watch:false` 停止。

> ⚠️ **桌宠当前不会在请求里传截图**。看屏幕要么你后端自己截，要么忽略这个接口——
> 不实现的话，她看不到屏幕，其余功能不受影响。

## 5 · 语音合成（可选）

```
POST /api/socialV2/voice-preview
{ "text": "要念的话" }
→ 200，响应体是 JSON：
  { "ok": true, "file": "/远端绝对路径/voice/xxx.mp3", "ms": 1234, "kb": 88, "label": "GPT-SoVITS" }
```

⚠️ **不是音频二进制**（早期版本文档写错了，代码从来不收二进制）。

桌宠拿到 `file` 后会再跑一条 `scp -q -o BatchMode=yes <sshHost>:<file> <本地 voice/>`
把文件拉回本机（超时 30s），然后通过 `denia://voice/<basename>` 播放。
所以 `file` 必须是**后端机器上的绝对路径**，且 `sshHost` 要能免密登录
（代码用了 `BatchMode=yes`，没配免密会秒退）。

不实现时，她只有气泡、**不会有声音** —— 联机模式**不会**退回 Windows 系统语音
（系统 TTS 兜底只在独立模式分支里，见 `接口总览.md` §5.5 的说明）。

## 附：两种实现模式

### A · 直接话术型（简单，适合大多数情况）

收到 `pet-chat` → 调你的模型 → 把输出放进 `reply` 返回。
桌宠会把它显示成气泡并念出来。**上下文由你自己按 `key` 维护。**

### B · 主动话术型（她的架构）

模型不直接回话，而是调"发消息"工具；消息发出后才被记成 `isSelf`。

实现要点：进请求前记一个**时间戳水位线**，投递后轮询自己的消息表，
捞出 `isSelf && time > 水位线` 的新消息，`join("\n")` 放进 `reply`。
**水位线必须用时间戳，不能数条数**——消息缓冲区是环形缓冲，
旧的被挤掉时"条数"可能不变，判据会失效。

## 错误与超时一览

| 情况 | 桌宠的表现 |
|---|---|
| 探活 1.2s 超时 | 尝试拉 SSH 隧道，连续 12 次（≈4.8s）不通则提示"连不上她" |
| `pet-chat` 超过 90s | 提示超时，气泡不显示 |
| 返回 `{"ok":false,...}` | 气泡显示错误信息 |
| `reply` 为 `""` | **正常**：她选择不说话，不报错 |
